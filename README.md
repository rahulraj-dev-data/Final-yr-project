# 🧠 AI-Powered Mental Health Analysis and prediction

An AI-powered mental health support application built with **Python and Streamlit**. The application provides an interactive conversational interface, sentiment analysis, facial emotion detection, user authentication, and AI-generated responses.

> ⚠️ **Disclaimer:** This application is intended for educational and supportive purposes only. It is not a substitute for professional medical or psychological advice.

---

## ✨ Features

- 🤖 **AI-Powered Conversations**
  - Generates contextual responses using Google's Generative AI.
  - Provides conversational mental health support.

- 😊 **Sentiment Analysis**
  - Uses VADER Sentiment Analysis to analyze the emotional tone of user messages.
  - Helps identify positive, negative, and neutral sentiment.

- 📷 **Facial Emotion Detection**
  - Uses OpenCV for camera-based facial detection.
  - Supports emotion-related analysis through computer vision.

- 🔐 **User Authentication**
  - Secure user registration and login.
  - Passwords are hashed using `bcrypt`.

- 🗄️ **MongoDB Database**
  - Stores user information and application data.
  - Uses PyMongo for database communication.

- 📊 **Data Processing**
  - Uses Pandas and NumPy for data manipulation and processing.

- 🖥️ **Interactive Web Interface**
  - Built using Streamlit.
  - Runs locally through a web browser.
